# Уровень станин — приложение для Android

Тот же экран, что и страница «Уровень станин X»: продольный, поперечный и взаимный уровень, расстояние между станинами, 3D-вид, графики, сохранённые замеры и сравнение. Работает без интернета, всё хранится в памяти телефона.

## Вариант 1. Android Studio (Windows)

1. Установите Android Studio: https://developer.android.com/studio (бесплатно). При первом запуске согласитесь на установку Android SDK.
2. Распакуйте этот архив в папку без кириллицы в пути, например `C:\Android\TitanLevel`.
3. Android Studio → **File → Open** → выберите папку `TitanLevel`. Дождитесь окончания «Gradle sync» внизу (первый раз скачивается несколько минут).
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Внизу справа появится «APK(s) generated» → **locate**. Файл: `app\build\outputs\apk\debug\app-debug.apk`.
6. Скопируйте APK на телефон и откройте. Телефон спросит разрешение «Установка из неизвестных источников» — разрешите для файлового менеджера.

Можно и без копирования: подключите телефон по USB с включённой «Отладкой по USB» и нажмите зелёный ▶ Run.

## Вариант 2. GitHub, без Android Studio

1. Создайте на github.com пустой репозиторий и загрузите в него содержимое папки `TitanLevel` (Add file → Upload files, вместе с папками `.github`, `app`, `gradle`).
2. Вкладка **Actions** → «Сборка APK» запустится сама (или Run workflow).
3. Через 3–5 минут в результате сборки появится архив **TitanLevel-apk** с файлом `app-debug.apk`.

## Важно

- Данные хранятся внутри приложения. При удалении приложения они пропадут.
- Замеры в приложении и на странице в claude.ai — раздельные.
- Обновление экрана: замените `app/src/main/assets/index.html` и соберите заново, увеличив `versionCode` в `app/build.gradle`.
